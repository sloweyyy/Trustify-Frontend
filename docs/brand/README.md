# Trustify brand review — Phase 1

Start with [brand-identity.md](brand-identity.md) and [index.html](index.html). The board is self-contained apart from local assets, has Vietnamese labels, and works offline with the bundled font. Open directly in a browser, or serve the repository with a local static server.

- [Existing-screen audit](audit/existing-screen-audit.md) and [screenshot gallery](audit/index.html): 74 before screenshots across Public, User, Notary, Admin and chatbot.
- [Brand board PNG](previews/brand-board.png) and [mobile board PNG](previews/brand-board-mobile.png).
- `logos/`: 3 directions × favicon/app icon/header × color/mono/inverse = 27 SVGs.
- `applications/`: 5 brand applications plus Vietnamese typography specimen, all SVG.
- `previews/`: PNG renditions, logo comparisons and 16/32px favicon checks.
- [Contrast evidence](contrast-checks.json), [font coverage](font-checks.json), [validation](validation.md), [asset licenses](assets-and-licenses.md).

Rebuild vectors and contrast evidence:

```sh
python3 docs/brand/tools/generate-assets.py
python3 docs/brand/tools/check-fonts.py
```

Re-render PNGs with an existing Playwright installation (documentation tooling only; no production dependency added):

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright node docs/brand/tools/render-previews.cjs
```

The renderer starts and closes its own loopback static server, waits for fonts, checks SVG text bounds and checks the board at 390px. Audit screenshots are historic live evidence, not regenerated by the brand renderer.
