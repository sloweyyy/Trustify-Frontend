# Design 01 — Complete route gallery

Baseline: production main after Logo B (merged PR #8). After: local design/01 theme build against the same QA API. 1440×1000 desktop and 390×844 mobile. All 36 role/route views are included, including invalid/reset/payment-result states without mutating requests. Data and timestamps may change between captures. Vercel authenticated click-through images are prefixed `vercel-`.
